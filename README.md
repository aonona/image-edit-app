# image-edit-app

ブラウザだけで「アップロード → 選択 → モザイク or トリミング → Undo → Reset → ダウンロード」までできる画像編集アプリです。
JavaScript は `index.html` 内にインラインで含まれているため、`index.html` をブラウザで開くだけで動きます。

## できること

- 画像ファイルをアップロードして Canvas に表示できます。
- Pointer Events でマウスもタッチ操作も共通化されているので、PC でもスマホでも操作できます。
- スケーリング計算 (`scaleX`, `scaleY`) を使っているので、キャンバスの見た目サイズと内部解像度が異なる場合でも座標がずれにくいです。
- ドラッグした選択範囲内だけにモザイクやトリミングを適用できます。
- モザイクの粗さはスライダーで変更できます。
- Undo（一つ戻る）は、赤い選択枠を含まない編集済み画像データを履歴に保存して復元します。
- Reset は、画像読み込み直後の `originalImageData` を復元します。
- Download は、キャンバスの画像を赤枠なしの PNG としてダウンロードします。

## 使い方

1. `index.html` をブラウザで開きます。
2. 画像をアップロードします。
3. キャンバス上で編集したい範囲をドラッグします。
4. 必要に応じてモザイク粗さを調整します。
5. 「モザイク」または「トリミング」を押します。
6. 必要に応じて「一つ戻る」「リセット」「ダウンロード」を使います。
